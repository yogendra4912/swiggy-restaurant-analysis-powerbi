## 📌 Project Overview

This project presents an interactive restaurant analytics
dashboard built using Microsoft Power BI.

The dashboard analyzes restaurant-level data to understand
restaurant availability, ratings, pricing, cuisine preferences,
locations, and other factors that can influence customer
choices and restaurant performance.

---

## 🎯 Business Problem

Food delivery platforms such as Swiggy operate across
multiple cities and restaurants with different cuisines,
price ranges, ratings, and customer preferences.

The objective of this project is to analyze restaurant data
and identify patterns that can help answer questions such as:

- Which locations have the highest restaurant presence?
- Which cuisines are most popular?
- What is the distribution of restaurant ratings?
- How does pricing vary across locations?
- Which restaurants have strong ratings?
- Which areas have higher-priced restaurants?
- What patterns can be observed across restaurant categories?

---

## 🎯 Project Objectives

1. Analyze restaurant distribution across locations
2. Understand cuisine-wise restaurant availability
3. Analyze restaurant ratings
4. Study pricing patterns
5. Compare restaurant performance across locations
6. Identify high-performing restaurants

## 📊 Dashboard Features
